This is the documentation for GazeTrack, an asynchronous, event-driven library and software stack for building real-time gaze projection systems. It provides a decoupled core runtime API for composing gaze tracking and scene analysis pipelines, along with a prebuilt, end-to-end application for projecting gaze data onto live scenes.

Head to the [Getting Started](./getting-started.mdx) guide to learn how to get started with GazeTrack.

Please refer to the [API Reference](../core) in order to integrate GazeTrack into your own applications.

:::note
Not a programmer? Use the [Prebuilt App](./using-the-prebuilt-app.mdx) for a user-friendly, end-to-end pipeline for real-time projection of gaze data onto live scenes.
:::

The prebuilt app should be sufficient for the majority of use cases, as it was part of our production pipeline.

The following example shows how to use the prebuilt app assuming a basic setup.

---

### Using the binary

Download the binary from our [Github release](https://github.com/cityuscm/GazeTrack/releases)

```bash
# platform can be linux, darwin(macos), or windows depending on your os
./gazetrack-web-<platform>
```

```bash

just sync

# run the app
just run
```

Or install dependencies and run manually:

```bash
# Install backend dependencies
cd backend && uv sync

# Install frontend dependencies
cd frontend && bun install

# Build the frontend
cd frontend && bun run build

# Copy the frontend artifacts to the backend
cp -r frontend/build/* backend/packages/web/src/gazetrack_web/ui/

# Run the app
cd backend && uv run gazetrack-web
# or
python -m uvicorn gazetrack_web.app:app --host 0.0.0.0 --port 8000
```

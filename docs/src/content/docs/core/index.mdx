## Overview
The core runtime API provides a comprehensive set of modules for building gaze tracking and scene analysis pipelines.

The API is organized into modular components that can be composed together to create custom gaze tracking and scene analysis pipelines. It exposes a clean, composable interface for building gaze tracking systems.

The decoupled design allows for flexible composition of different components, enabling developers to mix and match modules based on their specific requirements.
Abstract base classes and protocols define the contracts that all implementations must follow, ensuring consistency across the system while enabling flexible extension.
